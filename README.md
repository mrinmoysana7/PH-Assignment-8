# 📖 Project Overview

**Merbleva** is a modern luxury-inspired tiles gallery web application built with **Next.js App Router**.  
The platform showcases premium tile collections with elegant UI/UX, secure authentication, responsive layouts, dynamic routing, and modern luxury aesthetics.

This project was developed as an assignment project with a strong focus on:

- ✨ Luxury UI/UX Design
- 🔐 Authentication System
- 📱 Responsive Layout
- ⚡ Dynamic Routing
- 🎨 Premium User Experience
- 🧩 Clean Code Architecture

---

# 🎯 Project Purpose

The purpose of this project is to create a premium tiles showcase platform where users can:

✅ Browse luxury tile collections  
✅ Search and explore tiles easily  
✅ View detailed tile information  
✅ Register and login securely  
✅ Manage personal profile information  
✅ Experience a smooth responsive luxury UI
